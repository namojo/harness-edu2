# 교육 사이트 QA

## 이 QA가 다른 QA와 다른 점

**"파일이 있는가"는 검증이 아니다.** 이 사이트의 결함은 거의 전부 **두 곳에 있는 같은 정보가 어긋나는 것**에서 나온다. 원고와 HTML, 웹의 브리프와 정본 브리프, 개념 페이지의 패턴 이름과 실습 페이지의 패턴 이름, 링크와 실제 파일.

그래서 QA의 단위는 파일이 아니라 **경계면**이다.

| 경계면 | 무엇을 비교하나 | 자동화 |
|---|---|---|
| 원고 ↔ HTML | 원고의 문장·표·체크리스트 항목이 페이지에 빠짐없이 들어갔는가 | 부분 |
| **웹 브리프 ↔ 정본 브리프** | 실습 브리프가 한 글자도 다르지 않은가 | **완전 — `check_briefs.py`** |
| 개념 ↔ 실습 | 패턴 이름·정의가 동일한가 | 부분 — `check_site.py` |
| 네비게이션 ↔ 파일 | 모든 `href`가 존재하는 파일·앵커를 가리키는가 | **완전 — `check_site.py`** |
| 이관 설치가이드 ↔ 원본 | 명령어·절 번호·앵커가 보존되었는가 | **완전 — `verify_port.sh`** |
| 실습 2 산출물 ↔ 실습 3 입력 | 실습 3이 요구하는 입력을 실습 2가 실제로 만드는가 | 수동 |
| **웹 다운로드 링크 ↔ 저장소 실물** | 링크한 파일이 저장소에 실제로 있고 200으로 응답하는가 | **완전 — `check_assets.sh`** |
| 매니페스트 ↔ 페이지 | 매니페스트의 URL·용량이 페이지에 적힌 것과 같은가 | 부분 |

## 점진적으로 검증한다

전체가 완성된 뒤 한 번 도는 것은 늦다. 실습 3장이 다 나온 뒤에 골격 불일치를 발견하면 세 번 고쳐야 한다.

**페이지 하나가 완성될 때마다** 그 페이지와 그것이 닿는 경계면을 검사한다:

| 완성된 것 | 즉시 검사할 경계면 |
|---|---|
| 설치가이드 이관 | 이관↔원본, 링크↔파일, `#curriculum`→`#flow` 재배선 |
| 홈 | `id="flow"` 존재, 링크↔파일 |
| 개념 페이지 | 원고↔HTML, 출처 표기 존재 |
| 실습 1 | **브리프↔정본**, 개념↔실습(패턴 이름), 체크리스트 판정 가능성 |
| 실습 2 | 위 + 산출물 정의 |
| 실습 3 | 위 + 실습2 의존성 고지·우회 경로, **자산 다운로드 링크 200 확인** |
| 저장소에 `workshop/` push | 모든 raw URL 재검증 — **push 전에 만든 링크는 전부 404였다** |

## 스크립트로 잡을 것 / 사람이 잡을 것

**스크립트로 한다** — 사람 눈으로 보면 반드시 놓친다:
- 링크·앵커 대상 존재
- 브리프 문자 단위 일치
- 제목 레벨 순서
- 잔여 문자열 (`harness-edu`, `chapters/`, `차시`, `#curriculum`)
- 자산 파일 존재
- SVG의 `role`/`title`/`desc`
- 프롬프트 `<pre>` 밖 배치

```bash
python3 .claude/skills/edu-site-qa/scripts/check_site.py docs
python3 .claude/skills/edu-site-qa/scripts/check_briefs.py docs _workspace/briefs
bash   .claude/skills/edu-site-qa/scripts/check_assets.sh docs
bash   .claude/skills/install-guide-port/scripts/verify_port.sh docs
```

**`check_assets.sh`는 네트워크를 쓴다.** 오프라인이면 "미검증"으로 보고하고 통과로 처리하지 않는다. 다운로드 링크는 이 사이트에서 유일하게 외부에 의존하는 부분이므로, 검증을 생략하면 학습자가 교실에서 처음 발견한다.

**사람이 판단한다** — 스크립트가 흉내낼 수 없다:
- 체크리스트 항목이 학습자 혼자 O/X를 매길 수 있는가
- 예상 팀 표가 "정답"으로 읽히지 않는가
- 분량이 학습 시간 안에 소화 가능한가
- 학습자 시점으로 홈 → 실습 3까지 끊김 없이 갈 수 있는가
- 개념 페이지가 실습 페이지 합계보다 길지 않은가

### 판정 불가능한 체크리스트 찾기

실습 페이지의 검토 항목 중 아래 표현이 들어간 것은 **결함**이다. 학습자가 판정할 수 없어서 전부 O가 되고, 체크리스트가 무의미해진다.

```bash
grep -nE '적절(한|하)|충분(한|하)|품질이 (좋|높)|잘 (되|나)|논리적|명확한가|우수' docs/practice/*.html
```

걸린 항목은 `MAJOR`로 올린다.

### 복사 버튼은 실제로 눌러 본다

스크립트로는 `data-copy` 버튼과 `<pre>`의 존재만 확인된다. **`site.js`의 셀렉터가 실제로 그 `<pre>`를 찾는지**는 브라우저에서 눌러 봐야 안다. 셀렉터 불일치는 조용히 실패한다 — 버튼은 눌리고 "복사됨"도 뜨지 않는다.

```bash
cd docs && python3 -m http.server 8765
# 실습 1·2·3의 복사 버튼을 각각 눌러 텍스트 에디터에 붙여넣는다
```

확인할 것: ① 행 수가 5행인가 ② 실습 2의 `위한  마케팅` 이중 공백이 살아 있는가 ③ `<span>` 같은 태그가 섞이지 않았는가

## 결함 보고 형식

**재현 조건과 학습자 영향을 함께 쓴다.** "링크가 깨졌다"로는 누가 무엇을 고쳐야 하는지 알 수 없다.

```markdown
### [BLOCKER] 실습 3 샘플 자산 누락
- 위치: docs/practice/3-pptx.html:142
- 현상: `../assets/sample.pptx` → 파일 없음
- 학습자 영향: 실습 3 시작 단계에서 다운로드 실패. 40분 실습이 진행 불가
- 담당: practice-designer (자산 확정) → web-builder (배치)
```

| 심각도 | 기준 |
|---|---|
| `BLOCKER` | 실습 진행이 불가능하다 (프롬프트 오류, 자산 누락, 깨진 필수 링크) |
| `MAJOR` | 학습자가 오해한다 (패턴 이름 불일치, 판정 불가 체크리스트, 예상 팀이 정답처럼 읽힘) |
| `MINOR` | 다듬기 (오타, 여백, 표현) |

## 통과한 것도 기록한다

무엇을 검사했고 무엇이 통과했는지 남기지 않으면, 다음 실행에서 같은 검사를 처음부터 다시 해야 한다. `_workspace/06_qa_report.md`에 세 목록을 둔다: **결함 / 통과 / 미검증**.

**미검증을 통과로 보고하지 않는다.** 스크립트가 실패하면 "검사 실패 — 미검증"으로 명시한다. 이것이 QA의 최악의 실패다.

## 회귀 검사

이전 리포트가 있으면 **덮어쓰지 않는다.** 이전 결함이 해소되었는지 먼저 확인해 `[해소]`로 표시하고, 새 결함을 아래에 추가한다. 반복되는 결함 패턴이 보이면 그것은 개별 결함이 아니라 스킬이나 골격의 문제이므로 `edu-architect`에게 에스컬레이션한다.

## 학습자 시점 통과 테스트

마지막에 반드시 한 번. 링크만 눌러 아래 경로를 끝까지 간다. 끊기는 지점이 학습자가 이탈하는 지점이다.

```
홈 → 설치가이드 홈 → (OS 선택) 공통 준비 → 홈 복귀 → 개념
   → 실습 1 → 실습 2 → 실습 3 → 마무리
```

각 페이지에서 확인: 상단 3줄이 있는가 · 다음으로 가는 링크가 있는가 · 현재 위치가 네비게이션에 표시되는가.

## 의도된 불일치 — 결함으로 잡지 않는다

아래는 교육적 판단으로 원본과 다르게 한 것이다. 이 목록에 없는 불일치는 결함이다.

| 항목 | 원본 | 교재 | 근거 |
|---|---|---|---|
| 아키텍처 패턴 개수 | 8개 | 6개 + 각주 2 | `harness-concept-source` |
| 메타스킬 단계 | Phase 0~7 | 6단계 + 각주 | 같음 |
| 실습 3 브리프 | pptx 슬라이드 20 원문 | 하네스 구성 브리프로 확장 | `practice-briefs.md` §실습 3 |
| 설치가이드 차시 참조 | 1~7차시 | 실습 1~3 또는 삭제 | `install-guide-port` §2 |
| 설치가이드 저장소 URL·폴더 경로 | `namojo/harness-edu`, `~/harness-edu` | **그대로 유지** | `install-guide-port` §4-1 — 치환하면 51곳이 깨진다 |
| 설치가이드 `workshop/` 안내 문장 | 없음 | 폴더 구조 트리에 1행 추가 | `install-guide-port` §대상 파일 — 무손실 원칙의 유일한 예외 |

의심되면 해당 스킬 문서를 확인하고, 거기에도 없으면 `[판단 필요]`로 리포트에 올린다. 임의로 고치지 않는다.
