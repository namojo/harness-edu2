# 용어사전 · 확정 표기

| 용어 | 확정 표기 | 금지 표기 | 첫 등장 시 붙이는 한 줄 풀이 |
|---|---|---|---|
| harness | 하네스 | 하니스, Harness(본문에서) | 업무 설명을 AI 팀 구조로 바꿔 주는 도구 |
| agent | 에이전트 | 요원, 상담원, 에이전시 | 특정 역할을 맡은 AI 담당자 — **누가** |
| skill | 스킬 | 기능, 능력, 역량 | 그 담당자가 따르는 절차와 기준 — **어떻게** |
| orchestrator | 오케스트레이터 | 지휘자, 조율자, 총괄기 | 누가 언제 어떤 순서로 일하는지 정해 둔 것 |
| agent team | 에이전트 팀 | 멀티에이전트, 팀에이전트 | 서로 대화하며 일하는 에이전트 묶음 |
| brief | 브리프 | 지시문, 요청문 | 하네스에 주는 업무 설명 한 편 |

## 패턴 6종 (harness-concept-source 정본 · 개념·실습 페이지 공통)

| 확정 표기 | 금지 표기 |
|---|---|
| 파이프라인 | 순차 처리, 파이프 |
| 팬아웃 / 팬인 | 분산-수집, 팬-아웃, 병렬통합 |
| 전문가 풀 | 전문가 그룹, 스페셜리스트 풀 |
| 생성-검증 | 생성-검수, 제작-리뷰 |
| 감독자 | 슈퍼바이저, 관리자 |
| 계층적 위임 | 위계 위임, 재귀 위임 |

## 표기 규칙

- `프롬프트`와 `브리프`를 혼용하지 않는다. 하네스에 주는 업무 설명 = **브리프**, 일반적인 AI 입력 = 프롬프트.
- 실습은 `실습 1` / `실습 2` / `실습 3`. `1차시`·`Practice 1`·`실습1`(붙여쓰기) 금지.
- 저장소는 `namojo/harness-edu`, 사이트는 `harness-edu2`. 둘을 혼동시키지 않도록 저장소를 말할 때는 항상 `namojo/` 접두사를 붙인다.
