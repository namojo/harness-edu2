# 사이트맵 · 확정

## 페이지 맵 (본문 5장 + 이관 5문서)

| 파일 | 페이지 | 학습 목표 (덮을 때 할 수 있게 되는 것) | 시간 |
|---|---|---|---|
| `docs/index.html` | 홈 | 120분이 어떤 순서로 흐르는지 말할 수 있다 | 3분 |
| `docs/concept.html` | 개념 | 내 일이 어떤 패턴인지 3가지 질문으로 판단할 수 있다 | 15분 |
| `docs/practice/1-youtube.html` | 실습 1 | 업무 설명 한 문장으로 전문가 팀을 만들 수 있다 | 25분 |
| `docs/practice/2-marketing.html` | 실습 2 | 독립 조사 → 통합 → 별도 검토를 프롬프트 한 편에 담을 수 있다 | 30분 |
| `docs/practice/3-pptx.html` | 실습 3 | 앞 실습 산출물을 다음 입력으로 재사용하고 내용·형식을 나눠 검토할 수 있다 | 40분 |
| `docs/install/*` | 설치가이드 5문서 | (이관) 실습 환경을 스스로 준비할 수 있다 | 사전 25~35분 |

**페이지를 늘리지 않았다.** FAQ·용어집·심화패턴·트러블슈팅 모음·다운로드 페이지는 전부 "이것 없이 120분 완주가 가능한가"에서 걸러졌다. 트러블슈팅은 각 실습의 "이럴 때는" 블록, 다운로드는 각 실습의 "준비물" 블록에 분산했다.

## 네비게이션 (전 페이지 동일)

```
과정 홈 · 개념 · 실습 1 · 실습 2 · 실습 3 · 설치가이드
```

현재 페이지에만 `aria-current="page"`.

## 학습 동선과 페이저

| 페이지 | ← 이전 | 다음 → |
|---|---|---|
| 홈 | — | 설치가이드 |
| 설치가이드 홈 | 과정 홈 | 공통 준비 · Windows |
| 공통 준비 (Win/Mac) | 설치가이드 | **실습 1** |
| 개념 | 과정 홈 | 실습 1 |
| 실습 1 | 개념 | 실습 2 |
| 실습 2 | 실습 1 | 실습 3 |
| 실습 3 | 실습 2 | 과정 홈 |

설치 완료 후 목적지는 **개념이 아니라 실습 1**이다. 설치를 끝낸 사람의 관심은 "이게 진짜 돌아가나"이고, 그 확인은 실습에서 된다.

## 필수 id

| 페이지 | id | 이유 |
|---|---|---|
| `index.html` | **`flow`** | 이관된 설치 문서 5개의 `#curriculum` 재배선 대상 |
| `index.html` | `practice` | 홈에서 실습 3개로 진입 |
| 실습 3장 | `준비물`, `브리프`, `체크리스트` | 실습 중 앵커 이동 |

## 홈 구성 (800자 이내)

1. 히어로 — 한 문장 가치 + 프롬프트 박스(실습 1 브리프 미리보기) + CTA 2개(설치가이드 / 개념)
2. `#flow` — **120분 흐름** 5단계 타임라인 (개념 15 · 실습 25 · 30 · 40)
3. `#practice` — 실습 3장 카드
4. 실습 파일 한 줄 안내 — `git clone` 한 번으로 받거나 각 실습 페이지에서 개별 다운로드
5. 1세대(harness-edu)와의 관계 한 줄 + 링크
