# 톤 규칙

- **경어체 평서형** (`~합니다`). 명령형(`~하세요`)은 실습 절차의 단계 문장에만.
- **한 문장 60자 이내**를 기본. 주장 두 개가 한 문장에 있으면 자른다.
- **굵게는 페이지당 15회 이내.**
- 전문용어는 **첫 등장에만** 괄호 풀이 한 줄. `assertion`·`JSON schema`·`CI` 같은 개발 용어는 쓰지 않는다.
- **비유는 한 페이지에 하나.**
- 예시는 사무실 언어로. "CI 파이프라인" → "품의 결재선", "코드 리뷰" → "타 부서 검토".
- 학습 목표 문장은 `~를 이해한다` 금지. `~를 만들 수 있다 / 구분할 수 있다 / 판단할 수 있다`.

## 분량 상한 (본문 텍스트, 도식·표 제외)

| 페이지 | 상한 |
|---|---|
| 홈 | 800자 |
| 개념 | 4,000자 |
| 실습 1 | 2,000자 |
| 실습 2 | 2,500자 |
| 실습 3 | 3,000자 |

실습 페이지 상한이 개념보다 낮은 것은 의도적이다. 실습 시간의 대부분은 읽는 시간이 아니라 AI를 돌리고 결과를 보는 시간이어야 한다.
