### ⑤ MCP·Python의 위계 하향 — 판단이 필요했던 지점

1세대는 MCP가 6차시 필수여서 Python도 필수였다. **harness-edu2의 실습 1·2·3에는 둘 다 쓰이지 않는다.**

그래서 설치가이드 홈의 `1번과 3번이 필수` → `1번(공통 준비)만 필수`로 내리고, MCP 문서 상단에 `선택` 고지를 넣고, Python 절(3-9)의 `6차시용` → `선택 · MCP 문서용`으로 바꿨다.

Python 절 자체는 **삭제하지 않았다** — 명령과 절 번호를 보존해야 하고, MCP를 해 보려는 학습자에게 여전히 필요하다. 다만 필수처럼 보이게 두면 25~35분 준비가 40분 이상이 되므로 표기만 내렸다.

### ⑥ 폴더 지도 트리 재작성 — 무손실 원칙의 예외 2곳

**(a) 실습 폴더 지도** (`index.html` §5) — 1세대 7차시 폴더(`xlsx/ 1차시`, `ad/ 2차시` …)를 그대로 두면, 이 과정에 존재하지 않는 차시를 배웠다고 학습자가 오해한다. `workshop/` 중심으로 재작성하고 1세대 폴더는 한 줄로 묶어 "이전 과정 자료 — 이 과정에서는 쓰지 않습니다"로 명시했다.

**(b) 저장소 내용 설명** — `생산 보고서 엑셀, 샘플 데이터, 과제 문서` → `실습 브리프, sample.pptx, 예시 전략보고서`. clone 후 실제로 보게 되는 것과 일치시켰다. `ls` 예상 결과에도 `workshop`을 추가했다.

두 곳 모두 학습자가 **clone은 성공했는데 자기 실습 폴더를 못 찾는 상황**을 막기 위한 것이다.
