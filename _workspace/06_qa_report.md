| 함정 | 정본 | 웹 | 클립보드 |
|---|---|---|---|
| 실습 1의 en dash `8–10분` (U+2013) | ✓ | ✓ | ✓ |
| 실습 2의 이중 공백 `위한  마케팅` | ✓ | ✓ | ✓ |
| 5행 구조 | ✓ | ✓ | ✓ (5행) |

**복사 경로 검증 방법:** 브라우저에서 `[data-copy]` → `closest('.code-card')` → `querySelector('pre')` 를 실행해 실제로 클립보드에 들어가는 문자열을 추출하고 정본과 비교했다. 실습 2 기준 180자 · 5행 · 이중 공백 보존 · 태그 없음.

브리프 박스를 기존 `.code-card.is-prompt` 로 만든 것이 결정적이었다 — `site.js` 의 셀렉터가 그대로 맞아 **JS를 한 줄도 고치지 않았다.** 새 클래스를 만들었다면 복사 버튼이 조용히 실패했을 것이다.

## 미해소 결함 6건 — 전부 이관분 유래

### [판정: 정상] 차시 잔여 1건
`install/index.html:208` — `이전 과정(7차시) 자료 — 이 과정에서는 쓰지 않습니다`

의도된 문장이다. 저장소에 1세대 폴더(`xlsx/`, `ad/` 등)가 실제로 있으므로, 이것을 지우면 학습자가 낯선 폴더를 보고 혼란한다.

### [MINOR · 원본 유래] 제목 레벨 건너뜀 5건
`install/` 5문서에서 `h2 → h4`. 사이드바 목차 블록의 `<h4>` 이며 `.side-toc h4{display:none}` 으로 **화면에는 보이지 않는다.** 스크린리더 목차만 영향.

**고치지 않은 이유:** 1세대 harness-edu에 이미 있던 결함이고, 이관의 무손실 원칙(명령어·절 번호·앵커 보존)을 지키기 위해 이관분 HTML을 건드리지 않았다. 태그를 바꾸면 `.side-toc h4` CSS도 함께 고쳐야 하고, 5문서 + CSS를 건드리는 변경이 된다.

**고치려면:** `<h4>` → `<p class="side-toc-label">` 로 바꾸고 CSS 셀렉터를 함께 갱신한다. 사용자 승인 사항.
