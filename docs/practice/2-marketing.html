실습 1에서는 하네스가 팀을 알아서 만들었습니다. 실습 2에서는 그 팀이 어떻게 일할지를 우리가 정합니다. 그러려면 먼저 하나를 구분해야 합니다.

이것은 멀티에이전트가 아닙니다이것이 멀티에이전트입니다
같은 질문을 여러 번 물어 답을 여러 개 받는 것. 관점이 늘어난 것처럼 보이지만 서로를 모릅니다. 담당을 나누고, 누가 누구에게 무엇을 넘기는지 정하는 것. 조사한 사람과 통합하는 사람과 검사하는 사람이 다릅니다.

구분 질문은 하나입니다 — 담당끼리 결과를 주고받아야 하는가. 주고받을 것이 없으면 그냥 여러 번 물어보는 것이고, 주고받아야 하면 구조가 필요합니다.

두 질문에 "예"가 나왔으므로 두 패턴을 겹쳐 씁니다. 하나를 고르는 것이 아닙니다 — 개념 페이지에서 짚은 그대로입니다.

💡

왜 굳이 구조를 지정하나요? 조사를 한 사람이 통합까지 하면, 자기가 찾은 것에 맞춰 결론을 만듭니다. 통합한 사람이 검토까지 하면, 거의 언제나 "문제 없음"이 나옵니다. 구조를 나누는 것은 능력을 늘리는 것이 아니라 편향을 끊는 것입니다.

브리프

위에서 정한 구조가 브리프 안에 문장으로 들어가 있습니다. 하네스에게 맡기지 않고 "독립적으로 조사한 뒤", "별도 리뷰어가"를 직접 씁니다.

COPY & RUN
[브랜드]의 [제품/서비스]를 위한  마케팅 전략보고서 하네스를 구성해줘.
시장·고객·경쟁·채널을 독립적으로 조사한 뒤 전략가가 통합하고,
별도 리뷰어가 근거·실행 가능성·누락을 점검하게 해줘.
최종 산출물은 1페이지 요약, 실행 우선순위 표, 측정지표를 포함해줘.
사실과 가정을 구분하고 모든 외부 주장에 출처를 남겨줘.

대괄호 두 곳만 바꿉니다. 실제 담당 브랜드가 있으면 공개된 정보 범위에서 쓰세요.

이 브리프 안에 패턴 두 개가 들어 있습니다

브리프의 문장패턴이 문장이 만드는 것
시장·고객·경쟁·채널을 독립적으로 조사한 뒤 전략가가 통합하고팬아웃 / 팬인조사자 4명이 서로를 기다리지 않고, 전략가 1명이 합칩니다
별도 리뷰어가 근거·실행 가능성·누락을 점검하게 해줘생성-검증만든 담당과 검사하는 담당이 다른 사람이 됩니다

"별도"라는 단어 하나가 에이전트 하나를 만듭니다. 이 단어를 빼면 전략가가 자기 결과를 자기가 검토합니다 — 그러면 거의 언제나 "문제 없음"이 나옵니다.

예상 팀

💡

정답이 아니라 기준선입니다. 조사자가 4명이 아니라 3명이어도, 이름이 달라도 괜찮습니다. 조사가 서로 독립이고 통합과 검증이 다른 담당이면 성공입니다.

역할책임전달물
시장 조사자카테고리 규모와 변화 방향사실 + 출처
고객 조사자니즈와 구매 장벽사실 + 출처
경쟁 조사자경쟁 포지션과 비어 있는 자리사실 + 출처
채널 조사자채널별 도달과 비용사실 + 출처
전략가네 조사를 하나의 선택으로 통합1페이지 요약 + 실행 우선순위 표 + 측정지표
리뷰어근거·실행 가능성·누락 점검검토 의견 + 수정 요청

예상 산출물

좋은 전략보고서는 네 층으로 읽힙니다.

관찰무슨 일이 일어나는가 — 사실 + 출처
해석왜 그런가 — 가정임을 밝힌 판단
선택그래서 무엇을 할 것인가 — 우선순위
측정무엇으로 성공을 판단하는가 — 지표

좋은 전략보고서는 정보보다 선택을 보여줍니다. 그래서 1페이지 요약에는 "무엇을 하지 않을 것인가"가 반드시 있어야 합니다. 그 문장이 없으면 그것은 아직 전략이 아니라 조사 결과입니다. 이것이 본인 결과를 판정하는 가장 강력한 기준입니다.

검토 체크리스트

7개 중 6개 이상이면 통과입니다. 2번과 4번은 이 실습의 핵심이라 반드시 통과해야 합니다.

증상이렇게 하세요
리뷰어가 "문제 없음"만 말한다리뷰 기준이 추상적이면 이렇게 됩니다. "근거 없는 주장, 실행 주체가 없는 항목, 누락된 관점을 각각 3가지씩 지적해 달라"로 구체화해 다시 실행하세요.
네 조사 결과가 서로 베낀 것처럼 같다조사자들이 같은 질문을 받은 것입니다. 관점별로 다른 질문을 지정하세요 — 시장은 규모, 고객은 장벽, 경쟁은 빈 자리, 채널은 비용.
사실과 가정 구분이 없다브리프 5행을 강조해 다시 실행하세요. 하네스가 스킬에 표기 규칙을 넣지 않은 것입니다 — "모든 판단 문장에 [가정] 을 붙여 달라"가 잘 먹습니다.
출력이 너무 길어 1페이지가 3페이지다"1페이지 요약은 600자 이내"처럼 분량을 숫자로 지정하세요.
30분을 넘긴다조사 항목에 상한을 두세요 — "관점별 사실 3개까지".
브랜드를 못 정해서 막힌다가상 브랜드로 하세요. 예시 전략보고서가 가상 브랜드로 쓰인 좋은 참고입니다.
