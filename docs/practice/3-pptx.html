샘플 형식으로 새 PPT 만들기

이 실습을 마치면 앞 실습의 산출물을 다음 입력으로 재사용하고, 내용과 형식을 나눠 검토할 수 있게 됩니다.

sample.pptx 는 렌더된 이미지 슬라이드입니다 — 텍스트를 복사할 수 없습니다.

그것이 이 실습의 의도입니다. 붙여넣기로는 아무것도 되지 않으므로, 눈으로 읽어 규칙을 언어로 정리하는 것부터 시작해야 합니다. "예쁘게 따라 해"가 통하지 않는 상태를 일부러 만든 것입니다.

이번 실습에서 확인할 것

REFERENCE샘플에서 규칙을 뽑습니다
CONTENT실습 2의 전략을 재사용합니다
SCOPE새 슬라이드 3장
FORMAT편집 가능하게 유지합니다
REVIEW내용과 형식을 따로 검토합니다

브리프

브리프가 요청하는 것은 두 갈래입니다 — 형식은 샘플에서, 내용은 실습 2에서. 이 둘을 분리해 말하는 것이 이 실습의 핵심 기술입니다.

COPY & RUN
sample.pptx의 형식과 디자인을 재해석해 전략 보고서를 PPT로 만드는 하네스를 구성해줘.
먼저 sample.pptx에서 형식 규칙 — 폰트 계층, 외곽 여백, 정렬선, 색의 역할, 카드·표현 방식, 한 장의 정보량 — 을 추출하게 해줘.
그 규칙과 실습 2에서 만든 마케팅 전략보고서를 이용해 새 슬라이드 3장을 만들어줘.
1장은 문제와 기회, 2장은 실행 우선순위, 3장은 측정과 다음 행동으로 구성해줘.
내용 리뷰와 형식 리뷰를 맡는 리뷰어를 각각 두고, 텍스트·표·도형은 편집 가능하게 유지해줘.

예시 전략보고서를 쓰는 경우 3행의 실습 2에서 만든 마케팅 전략보고서 를 example-strategy.md 로 바꿔 말하면 됩니다.

추출할 형식 규칙 6종 — 이것이 실습의 첫 단계입니다

"예쁘게 따라 해"라고 하면 AI는 자기 취향으로 만듭니다. 뽑을 항목을 지정하면 규칙이 언어로 남고, 다음에 재사용할 수 있습니다.

규칙무엇을 보는가
폰트 계층제목 / 소제목 / 본문 / 캡션의 크기·굵기 관계
외곽 여백슬라이드 가장자리의 안전 영역
정렬선요소들이 공통으로 시작하는 좌측 기준선, 열 구조
색의 역할지배색 / 강조색 / 상태색이 각각 어디에 쓰이는가
카드·표현 방식정보를 담는 반복 단위 (아이콘 + 라벨 + 수치 같은 묶음)
한 장의 정보량한 슬라이드가 다루는 메시지 개수

이 6개를 줄이거나 늘리지 마세요. 6개가 채워지면 같은 디자인의 다른 슬라이드를 계속 만들 수 있는 상태가 됩니다.

예상 산출물

3장짜리 의사결정 스토리입니다 — 문제 → 선택 → 측정.

장제목답해야 하는 질문
01문제와 기회왜 지금 이 타깃과 이 메시지인가?
02실행 우선순위무엇을 먼저, 누가, 언제 할 것인가?
03측정과 다음 행동무엇으로 성공을 판단할 것인가?

세 장 모두 편집 가능해야 합니다 — 텍스트는 텍스트 프레임, 표는 표, 도형은 도형. 이미지로 구운 슬라이드는 실무에 쓸 수 없으므로 실패로 봅니다.

이럴 때는

증상이렇게 하세요
슬라이드가 이미지로 나와 편집이 안 된다가장 흔한 실패입니다. 브리프 5행의 텍스트·표·도형은 편집 가능하게 유지해줘 를 다시 강조해 재실행하세요. "파워포인트에서 텍스트를 클릭해 수정할 수 있어야 한다"를 덧붙이면 확실합니다.
샘플과 전혀 다른 디자인이 나온다규칙 6종을 실제로 추출했는지 먼저 확인하세요. 추출을 건너뛰고 바로 만들면 이렇게 됩니다. "규칙 6종을 먼저 표로 정리해 보여 달라"로 단계를 끊으세요.
텍스트가 도형 밖으로 넘친다"한 장의 정보량" 규칙 위반입니다. "한 장에 메시지 1개, 근거 3개까지"로 제한해 재실행하세요.
한글이 깨지거나 폰트가 바뀐다시스템에 없는 폰트를 지정한 경우입니다. "맑은 고딕" 처럼 내 PC에 있는 폰트로 고정해 달라고 하세요.
실습 2 결과가 없다준비물의 예시 전략보고서를 쓰세요. 실습 3만 따로 해도 됩니다.
실행이 너무 오래 걸린다3장을 2장으로 줄이세요. 완성 경험이 장 수보다 중요합니다.

다음 단계 — 세 실습의 정리

세 실습은 난이도 순서가 아니라 한 팀이 성장하는 세 단계였습니다.

실습 1팀을 만든다 — 도메인 문장 → 전문 역할
실습 2구조를 고른다 — 독립 조사 → 통합 → 검토
실습 3산출물을 다듬는다 — 형식과 내용을 분리

이제 본인 업무로 브리프를 다시 써 보세요. 실습 1의 네 요소(목표·대상·역할·기준)를 그대로 쓰면 됩니다. 결과가 아쉬우면 결과를 고치지 말고 브리프와 하네스를 고치는 것 — 그것이 하네스 엔지니어링입니다.
