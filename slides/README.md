## 다시 만들기

```bash
cd slides/src && python3 build.py
```

`gen_a.py`(01~08) · `gen_b.py`(09~14) · `gen_c.py`(15~20)에 슬라이드 내용이, `base.css`에 디자인 시스템이 있습니다.
`build.py`는 HTML 생성 → **넘침 검사** → Chrome headless 렌더를 순서대로 실행합니다.

### 두 가지 자동 장치

**① 넘침 검사** — 1920×1080을 넘는 슬라이드는 렌더에서 조용히 잘려 나갑니다. 렌더 전에 playwright로 각 슬라이드의 실제 높이를 재서 넘치는 장과 원인 요소를 먼저 보고합니다.

**② 제목·설명 한 줄 자동 맞춤** — 한국어 제목은 길이가 제각각이라 폰트 크기를 손으로 맞추면 내용을 고칠 때마다 다시 어긋납니다. 렌더 직전 페이지 안에서 실제 텍스트 폭을 재고, 한 줄에 들어갈 때까지 1px씩 줄입니다(제목 최소 34px, 설명 20px). 표지와 섹션 구분 슬라이드는 2줄을 허용하므로 제외합니다.

### 레이아웃 규칙

- 페이지 번호와 하단 말꼬리를 두지 않습니다 — 하단 글상자와 겹칩니다.
- 하단 여백 96px을 확보하고, 본문은 `justify-content:space-between`으로 남는 높이를 요소 사이에 분배합니다. 글상자가 슬라이드 밑에 달라붙지 않고 하단이 비어 보이지도 않습니다.
- 제목과 설명은 항상 한 줄입니다.
