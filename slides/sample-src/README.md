# sample.pptx 생성 — 실습 3의 형식 참조 원본

**가상 브랜드 '핀치(PINCH)' 반려견 덴탈 츄 '데일리츄' 제안서** 5장 · 16:9 · 1.0MB

정본 위치는 `namojo/harness-edu` 저장소의 `workshop/practice-3-pptx/sample.pptx` 입니다.

## 왜 가상 브랜드인가

실습 3은 이 파일에서 **형식 규칙 6종**을 뽑는 것으로 시작합니다. 실제 브랜드의 제안서를 쓰면 공개 저장소 배포에 권리 문제가 남습니다. 그래서 원본의 디자인 문법만 계승하고 내용은 전부 가공했습니다.

**카테고리를 일부러 다르게 했습니다.** 실습 2의 예시 전략보고서는 오르빗 그래놀라(아침 대용식)이고 이 샘플은 반려견 덴탈 츄입니다. 둘이 같은 카테고리면 학습자가 "샘플의 내용을 쓰는 건가"로 혼동합니다 — 샘플에서 가져올 것은 형식뿐입니다.

## 다시 만들기

`codex-image` 스킬(= `codex exec` 의 `image_generation` 툴)로 5장을 병렬 생성합니다.

```bash
cd slides/sample-src
# codex exec --sandbox workspace-write --skip-git-repo-check --cd . \
#   -o /tmp/ci-N.md "이미지 생성 도구로 … ./sNN.png 로 저장. 경로만 한 줄로 보고."
# → 5개를 run_in_background 로 동시 실행 (프롬프트는 아래 참조)

python3 flatten.py     # 투명 배경 → 크림 합성 + 1920×1080 정규화
# jpg 변환 후 pptx 조립
```

### 반드시 필요한 후처리 — 배경 합성

**codex 의 `image_generation` 은 배경을 투명(alpha 0)으로 내보냅니다.** 실측 **67.5%** 가 완전 투명이었습니다. 프롬프트에 "opaque solid cream background" 를 명시해도 그렇습니다.

그대로 pptx 에 넣으면 뷰어에 따라 검게 보이거나 흰 배경이 되어 **"크림색이 지배색"이라는 형식 규칙 자체가 사라집니다.** `flatten.py` 가 크림 `#FAF0DC` 에 합성하므로 이 단계를 건너뛰지 마세요.

처음 생성 결과를 검은 배경으로 보고 "한글이 깨졌다"고 오판했는데, 실제로는 잉크색 본문이 투명 배경 위에서 보이지 않았을 뿐이었습니다. 합성 후에는 한글이 전부 정확합니다.

### 프롬프트 원칙

- **flat vector infographic, NOT a photograph** 를 명시 — 사진풍으로 흐르는 것을 막습니다
- 한글 문자열을 **따옴표로 정확히** 지정 — 의미만 설명하면 다른 문장이 나옵니다
- 색을 hex 로 지정하고 **"only three colors"** 를 명시
- 레이아웃을 위치로 서술 (top-left / left half / three evenly spaced columns …)
- 아이콘은 **simple white line icon inside a solid crimson circle** 처럼 형태를 지정
